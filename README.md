Midterm Examination Reflection

1. What is Git used for?
    Git is used to track changes that we made into our files. It helps us to see the older versions of our files whenever we need and when something goes wrong. 

2. What is the difference between Git and GitHub?
    The difference between the two is that Git is a tool that we are using to save and manage versions of our project. On the other hand, GitHub is where we upload those projects online so others like our project members can access it anywhere and even make changes. 

3. Why is branching useful?
    I think that branching is useful for us to try building new features without affecting the main project. This helps avoid making unnecesary mistakes in the main project ensuring that there is a backup of the stable or working version. If something breaks, the main branch is still safe.

4. What command did you use to upload your local commits to GitHub?
    I used git push origin main when uploading local commits to GitHub. This files will then be available to access by other people anytime and anywhere depending on the permissions set by the owner.
